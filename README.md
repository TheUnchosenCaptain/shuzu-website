# SHUZU — Anime Sneakers

A static coming soon page for SHUZU, built with plain HTML, CSS and JavaScript. It needs no build step and works by opening `index.html` directly.

## Local preview

Open `index.html` in a browser, or serve this folder with any static server.

## Before launch

- Replace `assets/shuzu-mark.svg` with the official logo if one is supplied. Preserve the filename or update the image path in `index.html`.
- Navigation, footer, and Stay tuned link to https://www.instagram.com/shuzu.in/.
- Update Open Graph metadata with the final production URL and social preview image when available.

## Deploy to GitHub Pages

1. Push this folder to the default branch of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and `/ (root)`, then save.
5. GitHub will publish the site at the Pages URL shown in Settings → Pages.

Because this is a static site, no Actions workflow, package install or build command is required.
